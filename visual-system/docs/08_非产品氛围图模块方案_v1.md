# THERUIZ AURA 非产品氛围图模块方案 v1

## 模块定位

`non_product_atmosphere` 是内容板块中的独立入口，Provider 固定为 Image2。它通过 Product Echo 将当前上传 Product Truth 的色彩、材质触感、光泽、季节感和情绪转译为生活空间与物件氛围；产品本身不进入画面。

模块独立只表示入口、内容类型、Prompt Registry、数量规划和复制流程独立。Prompt 编译的第一优先级仍是当前 THERUIZ AURA Active Visual System，其次是 Quiet Warm Luxury Brand Core，再是季节与全局视觉约束、模块禁区、Product Echo 和单张变化。

## 产品与人物边界

产品参考图只作为 `visual_echo_extraction_only` 使用。最终 Prompt 明确禁止上传产品、鞋履、替代产品、产品碎片、包装展示和其他鞋类对象。

最终 Prompt 同时禁止人物、模特、人脸、手、腿、脚、身体局部、倒影、轮廓、人物影子、上脚、穿搭和动作。人物、穿搭、动作、模特库均不进入本模块运行时。

## Product Echo Profile

每个生成计划包含 `ProductEchoProfile`，字段包括主回声色、辅助色、材质回声、情绪回声、季节回声、生活方式回声和禁止方向。颜色和材质不在代码中伪造；主产品特征由 Image2 读取当前上传 Product Truth，品牌规则负责降饱和、克制化和品牌化过滤。

## Prompt Registry

模块 Registry：

```text
contentType = non_product_atmosphere
provider = image2
promptVersion = non-product-atmosphere-image2-v1
status = active
```

Registry 覆盖 Active Visual System 继承、Brand Core、Product Reference Read-only、Product Echo、Life Moment、Scene/Object、Composition、Product/Footwear Prohibition、Person Prohibition、Multi-output Variation 和 Negative Constraints。

## 数量与规划

用户可主动选择 `1 / 3 / 5 / 8` 张。生成计划、Prompt 数量和复制数量严格一致。

默认槽位按以下方向编排：私人卧室、入户门厅、窗边阅读、回家后桌边、工作台、酒店旅行、采购回家、材质与光影留白。每张使用一个主要生活痕迹和少量辅助物件，不向用户暴露场景、道具、灯光或 Product Echo 参数。

同批次图片共享 Product Echo Profile，但通过场景空间、生活时刻、核心物件、光线、取景距离、材质组合和构图重心形成差异。

## QA 规则

硬性失败标签：`PRODUCT_VISIBLE`、`FOOTWEAR_VISIBLE`、`PERSON_VISIBLE`。模块运行时契约将产品、鞋履和人物可见性设置为 `forbidden`，并将模特、穿搭、上脚生成设置为 `disabled`。

后续人工 Image2 结果可继续使用 `PASS`、`WEAK_ECHO`、`OVER_TRANSLATED`、`GENERIC_LIFESTYLE`、`CATEGORY_DRIFT`、`ARTIFICIAL_STYLING`、`FAIL` 标签进行评估。

## 测试结果

- Domain/Prompt：Registry、Product Echo、可见性、数量、唯一性和 Active Visual System 继承测试通过。
- UI：独立入口、数量规划、Prompt 数量和控制项隔离测试通过。
- 现有 typecheck、build、Prompt、Studio、Action、Outfit、runtime migration 和 Playwright 回归需在提交前全部通过。

## 已知限制

当前项目没有自动 Image2 API 或视觉分析服务。本模块提供 Provider-ready Prompt、复制入口和生成计划审计，不伪造真实生图或自动视觉 QA 结果。实际产品回声强度、类别漂移和人物/鞋履是否真的出现在 Image2 结果中，仍需人工生成与人工检查。

## 后续扩展边界

后续可以在不改变模块边界的前提下增加真实产品视觉分析、人工 QA 结果回传和更多稳定生活槽位。不得接入其他 Provider，不得把本模块自动混入小红书、朋友圈、买家秀、官方、人物或产品展示内容。
