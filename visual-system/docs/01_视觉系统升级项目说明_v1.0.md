# THERUIZ AURA 视觉系统升级项目说明 v1.0

> 项目定位：先升级 THERUIZ AURA 的品牌视觉生产能力，再设计用户极简获得图片的方式。
>
> 核心逻辑：用户未来只需上传产品图片并选择用途，系统自动在 THERUIZ AURA 的品牌视觉体系下生成可直接使用的商业图片内容。

---

## 1. 项目背景

THERUIZ AURA 现有视觉系统已经具备较明确的品牌方向，包括：

- Quiet Warm Luxury（温感静奢）
- 成熟城市女性的真实客户感
- 克制、松弛、低饱和、自然光
- 产品准确、鞋型秀气、材质真实
- 不甜妹、不网红、不塑料、不硬广告
- 适用于卖货、种草和品牌形象建设的视觉内容

现阶段的问题不是缺少“商业拍摄”板块，也不是缺少更多用户选项，而是现有视觉系统仍然更接近一套品牌审美规则、Prompt 经验和单张图片判断标准。

下一步需要把它升级成一套能够自动完成视觉判断、内容编排和生产执行的品牌视觉系统。

---

## 2. 核心判断

### 2.1 不新增独立的“商业摄影”板块

商业摄影不是与“卖货、种草、品牌建设”并列的第四种视觉目标。

- 卖货、种草、品牌建设，回答的是“为什么做”。
- 商业摄影、AI 生成、视频生产，回答的是“怎么做”。

因此，商业摄影应作为系统内部的视觉生产能力，而不是让用户进入一个新的复杂板块进行配置。

### 2.2 不增加用户决策负担

THERUIZ AURA 已经拥有自己的品牌视觉风格，用户不应该重复决定：

- 场景
- 模特年龄和气质
- 穿搭
- 光线
- 构图
- 产品露出比例
- 卖货感与品牌感的权重
- 镜头结构
- Prompt 细节

这些专业判断应由系统自动完成。

### 2.3 用户未来只表达“产品”和“用途”

理想流程为：

```text
上传一组产品图片
→ 选择用途
→ 系统调用品牌视觉体系
→ 自动生成对应的内容方案
→ 输出可直接使用的图片组合
```

用户最多选择：

- 小红书
- 朋友圈
- 买家秀
- 官方内容

必要时增加轻量选项，例如图片数量或特殊要求，但不让用户进入精细化视觉配置。

---

## 3. 项目目标

本项目的目标不是增加新的页面或选项，而是升级 THERUIZ AURA 背后的视觉决策能力。

升级后，系统应能做到：

1. 自动继承品牌视觉风格。
2. 自动识别产品真实性要求。
3. 根据用途自动判断内容表达方式。
4. 自动选择适合的模特、场景、穿搭、动作、光线和构图。
5. 从单张图片生成升级为整组内容编排。
6. 自动生成 Prompt、参考图方案和交付结构。
7. 自动检查产品准确性、品牌一致性和商业可用性。
8. 为后续“上传产品＋选择用途＋自动生成”的极简产品流程提供底层能力。

---

## 4. 项目核心原则

### 4.1 品牌视觉优先

所有生成内容首先必须像 THERUIZ AURA，而不是像某个通用生图模型的作品。

### 4.2 产品真实性优先

视觉表达不得破坏：

- 鞋型
- 鞋头
- 鞋底厚度
- 裁片结构
- 材质
- 色彩
- 鞋带、鞋舌、鞋口和后跟关系
- 上脚后的真实形变

### 4.3 用途驱动，但不由用户精细配置

用途是用户输入，视觉策略是系统判断。

### 4.4 同一品牌，不同表达状态

小红书、朋友圈、买家秀和官方内容不是四套独立风格，而是同一品牌视觉母体在不同商业语境下的四种表达状态。

### 4.5 从“好看”升级为“可使用”

系统不仅判断图片是否好看，还要判断：

- 是否适合发布平台
- 是否完成内容任务
- 是否形成图组分工
- 是否可直接交付和使用

### 4.6 先建立专业判断，再隐藏专业判断

极简体验不是减少几个按钮，而是系统已经替用户完成了专业决策。

## 5. 视觉系统升级后的结构

### 5.1 品牌视觉母体

这是所有内容共同继承的长期规则，不由用户每次选择。

包含：

- 品牌气质
- 目标客群
- 色彩系统
- 光线系统
- 材质倾向
- 模特规则
- 人物状态
- 穿搭逻辑
- 场景边界
- 构图原则
- 镜头语言
- 内容禁区
- 品牌识别特征

### 5.2 Product Truth 产品真实性系统

由品牌资料、SKU 资料和产品参考图共同构成。

包含：

- 产品品类
- 结构与比例
- 颜色
- 材质
- 关键细节
- 必须保持的特征
- 允许的自然形变
- 禁止出现的问题

### 5.3 用途表达适配器

用户只选择用途，系统自动完成视觉转译。

#### 小红书

默认方向：

- 真实生活方式
- 可代入、可收藏、可模仿
- 弱硬广感
- 竖版优先
- 自然人物状态
- 穿搭参考价值
- 产品自然露出但必须清楚
- 图组具有轻叙事

#### 朋友圈

默认方向：

- 私人感和可信感
- 低制作痕迹
- 图片数量更精简
- 场景简单自然
- 一眼能看懂产品和穿搭
- 保留品牌质感但降低广告感

#### 买家秀

默认方向：

- 真实客户感优先
- 降低模特感和摄影感
- 人体比例真实
- 普通生活空间
- 穿搭容易模仿
- 允许适度日常瑕疵
- 产品真实性不得下降

#### 官方内容

默认方向：

- 品牌完整度最高
- 系列一致性最高
- 产品准确性最高
- 可形成主视觉、穿搭、产品重点、细节和生活方式的完整图组
- 适用于上新、首页、详情页、品牌传播和 Campaign

### 5.4 图组编排系统

系统不再只生成若干张相似图片，而是为每张图片分配内容角色。

可能的图片角色包括：

- 主视觉
- 封面图
- 完整穿搭图
- 行走动态图
- 鞋履重点图
- 材质细节图
- 日常使用图
- 镜前自拍图
- 静物图
- 情绪补充图

图组结构由用途、产品特点和品牌目标共同决定。

### 5.5 视觉执行系统

系统根据品牌母体、产品真实性和用途，自动决定：

- 模特
- 场景
- 穿搭
- 动作
- 时间
- 光线
- 镜头
- 构图
- 图片比例
- 产品展示程度
- 文案留白
- 参考图排序
- Prompt 编译
- Negative Constraints

### 5.6 QA 与交付系统

至少包含以下判断：

- 产品准确性
- 品牌一致性
- 人物真实性
- 场景合理性
- AI 感控制
- 平台适配性
- 商业可用性
- 图组完整性
- 图片之间的一致性和分工

## 6. 本阶段需要完成的工作

### 6.1 梳理现有视觉资产

将现有资料划分为：

- 已稳定的品牌母规则
- 可复用的视觉资产
- 暂时性的 Prompt 经验
- 需要继续验证的规则
- 相互冲突或重复的规则

### 6.2 升级品牌视觉母体

把现有的风格描述转化成可执行的视觉判断规则。

重点不是增加形容词，而是明确：

- 什么情况下选择什么
- 什么情况下禁止什么
- 哪些规则始终固定
- 哪些规则可根据用途变化
- 变化范围有多大

### 6.3 建立用途表达规则

完成小红书、朋友圈、买家秀、官方内容四个适配器的内部规则。

每个用途至少明确：

- 内容目标
- 画面真实度
- 广告感强弱
- 人物状态
- 场景倾向
- 产品展示优先级
- 图片比例
- 图组角色
- QA 标准

### 6.4 建立图组编排逻辑

明确系统如何从一个产品自动生成一组具有不同任务分工的图片，而不是重复生成同类型画面。

### 6.5 建立可执行映射

把视觉判断映射到：

- 场景库
- 模特库
- 穿搭库
- 动作库
- 镜头库
- Prompt 模块
- 产品真实性约束
- QA 规则

### 6.6 进行真实生成验证

使用 THERUIZ AURA 的真实 SKU 进行测试，验证：

- 同一产品在不同用途下是否保持同一品牌身份
- 不同用途之间是否存在合理差异
- 图组是否有清晰分工
- 是否能减少人工选择和 Prompt 修改
- 是否能直接用于实际发布

---

## 7. 本阶段明确不做的内容

为了避免项目过早进入前台功能开发，本阶段暂不重点处理：

- 用户上传页面的最终交互设计
- 用途选择页面的最终 UI
- 图片额度和收费逻辑
- 一键生成按钮流程
- 完整的平台权限系统
- 真实生图 API 接入
- 让用户选择大量场景、模特、光线和构图参数

这些内容将在视觉系统稳定后进入下一阶段。

## 8. 下一阶段：用户极简获得图片方案

当视觉系统升级完成并验证有效后，再进入第二阶段。

理想用户流程：

```text
第一步：上传产品图片
第二步：选择用途
第三步：点击生成
第四步：获得已经编排好的图片内容
```

系统后台自动完成：

- 产品识别
- 品牌风格继承
- 内容策略判断
- 图组规划
- 场景和模特调用
- Prompt 编译
- 图片生成
- QA
- 图片排序
- 平台规格适配

这一阶段的目标是：

> 用户提供产品和用途，系统负责品牌化表达。

---

## 9. THERUIZ AURA 与普通生图平台的区别

普通生图平台通常要求：

```text
用户定义风格
→ 用户选择场景
→ 用户编写 Prompt
→ 用户反复抽卡
→ 用户自己判断图片能否使用
```

THERUIZ AURA / BM 的目标是：

```text
用户提供产品
→ 用户选择用途
→ 系统理解品牌
→ 系统完成视觉判断
→ 系统生成完整内容组合
→ 系统完成 QA
→ 用户直接使用
```

普通平台提供的是生成工具。

本项目要建立的是：

- 品牌视觉判断能力
- 产品真实性保护能力
- 商业内容规划能力
- 图组编排能力
- 持续一致的视觉生产能力

---

## 10. 项目成功标准

视觉系统升级完成后，应至少满足：

1. 用户不需要重新定义 THERUIZ AURA 的视觉风格。
2. 用户不需要手动选择场景、模特、穿搭、光线和镜头。
3. 同一 SKU 在不同用途下仍然保持统一品牌身份。
4. 小红书、朋友圈、买家秀和官方内容之间有明确但不过度割裂的差异。
5. 系统能够自动生成有角色分工的完整图组。
6. 产品结构、材质、颜色和比例保持准确。
7. 图片具备实际发布和商业使用价值。
8. 人工修改 Prompt 和反复试错明显减少。
9. 视觉规则能够继续迁移到其他品牌，而不是只依赖人工经验。
