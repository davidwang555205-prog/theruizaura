# 一、品牌视觉核心定义

## 1.1 核心定位

**Quiet Warm Luxury｜温感静奢**

THERUIZ AURA 的视觉不是冷漠、疏离、昂贵符号堆叠的传统 Quiet Luxury。

它表达的是：

- 温暖；
- 克制；
- 松弛；
- 真实；
- 成熟；
- 有触感；
- 舒服但不随便；
- 日常但有审美；
- 不费力的体面。

## 1.2 核心视觉命题

> 一个有审美、有生活经验的 25—46 岁城市女性，在真实而温暖的日常空间中，自然进入 THERUIZ AURA 的品牌世界。产品必须准确地参与画面，但不负责决定人物、场景和品牌气质。

# 二、正式视觉参考锚点结构

正式锚点分为三类，不得混为一类使用。

## 2.1 A 类｜生活方式母体锚点

作用：

- 定义真实城市女性；
- 定义生活温度；
- 定义自然光与人物状态；
- 定义产品如何进入日常生活；
- 定义“松弛但不随便”的尺度。

对应参考：

- A1｜坐姿完整产品露出
- A2｜站姿与城市过渡空间
- A3｜坐姿松弛与材质关系
- A4｜坐姿交叉腿与自然产品可见

## 2.2 B 类｜官方棚内人物锚点

作用：

- 定义官方人物图；
- 定义成熟模特与简洁造型；
- 定义暖灰棚拍边界；
- 定义正面、侧面、背面和鞋履近景；
- 防止棚拍滑向白底目录或夸张时装大片。

对应参考：

- B1｜鞋履近景与裙装比例
- B2｜背面全身与成熟人物
- B3｜正面全身与克制构图
- B4｜三分之四全身与侧向站姿

## 2.3 C 类｜产品呈现与材质锚点

作用：

- 定义产品静物图；
- 定义暖灰背景与留白；
- 定义产品轮廓、上脚、双鞋、后跟和俯视结构；
- 定义小而克制的品牌字标；
- 定义产品真实性与品牌价值如何同时存在。

对应参考：

- C1｜侧面轮廓与品牌留白
- C2｜上脚双鞋近景
- C3｜双鞋三分之四静物
- C4｜后跟材质与工艺特写
- C5｜俯视结构与鞋带状态

# 三、视觉决策优先级

所有后续图片必须按照以下优先级判断：

```text
产品真实性
＞
品牌视觉一致性
＞
用途适配性
＞
商业可用性
＞
单张视觉冲击力
```

任何图片即使“很好看”，只要产品不准确或明显偏离品牌母体，都不能进入正式交付。

# 四、人物母体

## 4.1 核心人物

品牌视觉人物覆盖：

- **25—46 岁城市女性**；
- 亚裔、轻混血或国际化面貌均可；
- 有稳定审美和真实生活感；
- 25—29 岁可以轻盈，但不得少女化、校园化或网红化；
- 30—39 岁自然承接品牌城市生活表达；
- 40—46 岁强调稳定、自信和生活经验，但不得刻意塑造成“贵妇”；
- 不使用极瘦、过度职业化的时装模特感。

年龄属于品牌人物母体，不由产品名称、颜色、材质、SKU 或产品分类决定。

## 4.2 人物状态

必须具备：

- 肩颈放松；
- 身体重心真实；
- 手部有自然受力；
- 表情平和；
- 允许自然看镜头，但不能默认每张都看镜头；
- 允许轻微微笑，但不能形成商业营业感；
- 头发有自然碎发和纹理；
- 皮肤真实，不蜡像、不塑料；
- 人物注意力可以在环境、动作或自身状态中。

## 4.3 人物禁区

禁止：

- 甜妹；
- 少女偶像；
- 网红凝视；
- 强烈商业微笑；
- 夸张扭胯；
- 职业模特式姿态；
- 极度冷漠；
- 明显假人感；
- 肢体比例拉长；
- 手部、重心和姿势不真实。

---

# 五、生活状态母体

THERUIZ AURA 的人物不是为了镜头存在，而是在生活中被看见。

## 5.1 正确状态

- 坐下稍作停留；
- 准备离开；
- 正在经过；
- 等待；
- 轻触桌面；
- 自然站立；
- 轻微整理衣物；
- 在门口、街角、住宅入口或室内外边界停顿；
- 动作轻，但能解释人物正在做什么。

## 5.2 错误状态

- 只有姿势，没有行为；
- 为了露鞋刻意抬脚；
- 反复使用同一套站姿；
- 每张图都像拍摄现场；
- 道具只为制造“高级感”；
- 人物和场景没有真实关系。

# 六、色彩母体

## 6.1 基础色

主要视觉底色：

- Cream White；
- Warm Beige；
- Soft Stone；
- Ivory；
- 燕麦；
- 暖灰；
- 亚麻本色；
- 柔和黑色；
- 浅蓝；
- 柔和棕色。

## 6.2 色彩结构

标准结构：

```text
低声量背景
+
克制穿搭
+
一个柔和产品变化
```

当图片角色需要产品成为视觉重点时，产品颜色可以成为画面中最明确的变化；生活方式图片也允许产品保持较低声量。无论权重高低，产品颜色都必须真实，且不能形成艳丽、卡通或过度潮流感。

## 6.3 色彩禁区

禁止：

- 高饱和糖果色主导；
- 强烈撞色；
- 冷科技蓝；
- 过度金黄滤镜；
- 所有画面都套米白模板；
- 背景抢过产品；
- 产品颜色失真。

---

# 七、光线母体

## 7.1 生活方式光线

优先：

- 明确来源的自然侧光；
- 上午或下午柔和阳光；
- 有高光和真实阴影；
- 肤色和白色衣物保留层次；
- 温暖但不过度发黄；
- 真实空间反射。

## 7.2 官方棚拍光线

优先：

- 柔和方向光；
- 暖灰背景；
- 人物与产品有立体度；
- 阴影干净但不被完全消除；
- 不做冷白电商灯箱感。

## 7.3 产品静物光线

优先：

- 表现皮革、麂皮和鞋底纹理；
- 柔和接触阴影；
- 产品真实落地；
- 不过曝；
- 不磨平材质；
- 不做 CGI 式轮廓光。

---

# 八、材质母体

视觉必须让人感到“可以触摸”。

需要表现：

- 真皮自然纹理；
- 麂皮绒面方向；
- 棉麻和衬衫的透气褶皱；
- 牛仔布的真实重量；
- 藤编、石材、木材和陶瓷的真实表面；
- 鞋底的半透明、橡胶或牛筋质感；
- 正常缝线和工艺细节。

禁止：

- 塑料皮革；
- 无纹理麂皮；
- 光滑 3D 材质；
- 背景像渲染场景；
- 衣服没有重量；
- 皮肤和产品同时过度磨皮。

---

# 九、穿搭母体

## 9.1 生活方式穿搭

应当：

- 成熟；
- 可模仿；
- 有城市日常感；
- 简单但不普通；
- 服务鞋履；
- 不依赖大 Logo。

典型方向：

- 白衬衫＋浅蓝牛仔；
- 象牙针织＋暖灰裤装；
- 浅色衬衫＋中长裙；
- 奶油背心＋宽松裤装；
- 轻薄针织＋柔和半裙。

## 9.2 官方棚拍穿搭

应当：

- 轮廓明确；
- 颜色有限；
- 黑、白、米、灰形成结构；
- 鞋履颜色成为变化；
- 正侧背面都能保持完整。

## 9.3 禁止

- 甜美少女装；
- 大量荷叶边；
- 过度潮牌化；
- 明显网红套装；
- 大面积 Logo；
- 复杂叠穿；
- 服装抢夺鞋履；
- 全部产品都套同一身米色衣服。

# 十、场景母体

## 10.1 生活方式场景

场景不按“地点名称”判断，而按生活逻辑判断。

优先：

- 半公共城市空间；
- 咖啡馆外部；
- 住宅或酒店入口；
- 店铺内外边界；
- 门口；
- 窗边；
- 街角；
- 住宅大堂；
- 电梯厅；
- 停车处到办公室的步道；
- 安静书店或杂志店；
- 真实家居过渡空间。

## 10.2 官方棚内场景

允许：

- 暖灰；
- 浅石；
- 燕麦；
- 奶油白；
- 低对比无缝背景；
- 少量真实地面纹理。

## 10.3 场景禁区

禁止：

- 空洞豪宅；
- 纯奢华酒店模板；
- 网红打卡点；
- 无生活行为的咖啡馆背景；
- 虚假 Pinterest 拼贴；
- 冷白摄影棚；
- 复杂廉价道具；
- 场景只为“看起来高级”。

# 十一、产品出现方式

## 11.1 生活方式图

必须：

- 至少一只鞋完整；
- 产品轮廓清楚；
- 脚、鞋、裤口关系真实；
- 产品自然进入动作；
- 鞋履成为穿搭和色彩落点；
- 不刻意怼鞋；
- 不因追求情绪而牺牲产品。

## 11.2 官方人物图

一组官方人物内容应覆盖：

- 正面全身；
- 三分之四角度；
- 背面；
- 鞋履局部；
- 上脚比例。

## 11.3 产品图

一组正式产品内容应覆盖：

- 侧面轮廓；
- 三分之四双鞋；
- 俯视结构；
- 上脚关系；
- 后跟或材质近景。

# 十二、构图母体

## 12.1 生活方式构图

- 人物不必始终居中；
- 场景有留白和真实结构；
- 产品位于画面自然落点；
- 人物、桌椅、包袋之间关系合理；
- 不使用夸张广角；
- 不拉长双腿；
- 不过度虚化背景。

## 12.2 官方棚拍构图

- 正面、侧面、背面角色明确；
- 大量留白；
- 人物比例正常；
- 产品不能被裙摆遮挡；
- 不连续生成大量只有轻微姿势变化的图片。

## 12.3 产品图构图

- 产品主体清楚；
- 上方有呼吸；
- 下方可保留字标；
- 道具极少；
- 轮廓完整；
- 阴影真实；
- 不悬浮。

# 十三、品牌字标规则

THERUIZ AURA 字标：

- 小而克制；
- 字距较大；
- 作为署名，不作为口号；
- 优先放在产品图下部；
- 不压产品；
- 不要求每张图片都出现；
- 生活方式图片默认不使用大 Logo；
- 手提袋和品牌卡片不能作为默认高级感工具。

# 十四、正式品牌识别锚点

## 14.1 成熟女性的安静生命力

人物真实、有判断、有生活，不甜美、不冷漠、不表演。

## 14.2 温暖的真实空间

无论街景、室内还是棚内，都必须有明确光线、真实材质和空间温度。

## 14.3 产品准确而自然地参与画面

产品必须保持真实、可识别，并与人物、穿搭和空间形成合理关系。产品是否成为视觉重点，由本张图片角色决定；产品不得反向决定人物年龄、场景或品牌气质。

## 14.4 克制中存在一个柔和变化

背景和穿搭维持低声量秩序，可以由产品颜色、材质或其他一个轻微元素带来变化；系统不得强制每张图都用产品承担唯一色彩变化。

## 14.5 近距离可触摸，远距离可代入

生活方式图与产品细节图必须同时存在，共同构成品牌表达。

# 十五、固定项与可变项

## 15.1 固定项

以下不能因用途变化而改变：

- 温感静奢；
- 25—46 岁有稳定审美的城市女性；
- 温暖、克制、松弛、真实；
- 产品真实性优先；
- 自然或温暖方向光；
- 真实材质；
- 低声量色彩秩序；
- 产品准确而自然地参与画面，其视觉权重由图片角色决定；
- 不网红、不甜妹、不塑料；
- 生活方式与产品证据必须共存。

## 15.2 可变项

允许变化：

- 模特具体面貌；
- 发型；
- 城市和空间；
- 室内或室外；
- 是否露脸；
- 季节；
- 穿搭单品；
- 产品颜色；
- 画面景别；
- 动作；
- 内容制作感；
- 是否有品牌字标；
- 生活方式、棚拍和静物的比例。

变化必须在固定母体范围内发生。

# 十六、上传驱动 Product Truth 与决策边界

## 16.1 核心原则

> **产品是事实来源，不是视觉导演。**

当次上传的一组产品图片，是当前任务唯一产品事实来源。

系统不得依据：

- 预设 SKU；
- 产品名称；
- 产品颜色；
- 产品材质；
- 产品系列；
- 历史产品定位；

直接匹配人物年龄、场景、穿搭、光线或品牌调性。

## 16.2 决策权限

### 品牌视觉母体决定

- 25—46 岁人物范围；
- 人物气质；
- 色彩秩序；
- 光线；
- 材质语言；
- 空间气质；
- 构图边界；
- 品牌禁区。

### 当次上传图片决定

- 产品轮廓；
- 鞋头；
- 鞋底；
- 裁片；
- 鞋带；
- 后跟；
- 颜色；
- 材质；
- 工艺细节；
- 可以安全生成的产品角度。

### 用途适配器决定

- 图组角色；
- 图片比例；
- 制作感；
- 产品可见度；
- 生活方式、棚拍和静物的组合；
- 渠道交付规格。

### 系统编排层决定

- 在已批准模特池中轮换人物；
- 场景、穿搭、动作和镜头；
- 避免近期内容重复；
- 图组内部的远、中、近景关系。

## 16.3 上传证据门禁

推荐至少上传：

1. 完整侧面或三分之四图；
2. 俯视或正面图；
3. 后跟或材质细节图。

证据不足时，系统不得猜测不可见结构，只能提示补充对应角度，或限制无法保证准确的镜头。

## 16.4 产品弱化的准确含义

产品弱化不等于产品模糊或不准确。

它意味着：

- 产品不负责定义品牌世界；
- 生活方式图不要求每张都以产品为最大主体；
- 人物、空间和生活状态可以先被感知；
- 产品准确地参与画面；
- 产品图和细节图仍承担完整产品证据；
- 产品可见度由图组角色决定，而不是所有图片统一处理。

# 十七、品牌一致性 QA

## 17.1 硬性淘汰

出现以下任一情况，直接淘汰：

1. 鞋型、颜色、材质或裁片明显错误；
2. 产品跑鞋化、厚底化或滑板鞋化；
3. 脚、鞋、裤口穿模；
4. 人体、手部、面部或重心明显错误；
5. 产品悬浮；
6. CGI、塑料或蜡像感明显；
7. 人物明显甜妹、网红或职业硬广模特化；
8. 场景与人物没有行为关系；
9. 产品不可识别；
10. 仅靠米白背景和自然光冒充品牌一致性。

## 17.2 品牌一致性评分

100 分：

- 产品真实性：30
- 人物母体：15
- 色彩与光线：15
- 真实材质：10
- 产品出现方式：10
- 构图与留白：10
- 品牌识别锚点完成度：10

建议：

- 90—100：可作为品牌正向参考；
- 80—89：可正式使用；
- 70—79：需修复；
- 70 以下：淘汰。

# 十八、系统调用规则

后续视觉生成不得直接复制锚点图片，也不得按 SKU 预设匹配视觉。

品牌表达链路：

```text
品牌视觉母体 v1.2
+
用途适配器
+
图组角色
+
系统多样性编排
```

产品准确性链路：

```text
当次上传图片
+
当前任务 Product Truth
+
参考图计划
+
产品 QA
```

两条链路在生成阶段合并：

```text
用户上传产品图片
→ 建立当前任务 Product Truth
→ 检查上传证据完整度
→ 调用品牌视觉母体 v1.2
→ 读取用途
→ 编排图组角色
→ 自动选择模特、场景、穿搭、动作和镜头
→ 编译 Prompt 与参考图计划
→ 生成
→ 产品 QA
→ 品牌 QA
→ 用途与图组 QA
```

系统必须遵守：

- 产品只定义真实外观；
- 产品不决定人物年龄；
- 产品不决定场景；
- 产品不决定品牌气质；
- 用户无需填写专业视觉参数；
- 年龄通过品牌模特池和内容多样性管理，不通过产品匹配。

# 十九、本阶段完成标准

Phase 2-C2 完成后，应满足：

1. 品牌视觉不再依赖零散 Prompt；
2. 13 张正式锚点拥有明确角色；
3. 生活方式、官方棚拍和产品图使用同一个品牌母体；
4. 所有固定项、可变项和决策权限已明确；
5. 后续用途适配不能重新定义品牌；
6. 新图片可以用统一规则判断是否属于 THERUIZ AURA；
7. 失败时能够指出具体违反了哪条规则；
8. 不再使用产品或 SKU 预设匹配人物、场景和调性；
9. 当次上传图片成为当前任务唯一产品事实来源。

# 二十、下一阶段

下一阶段进入：

## Phase 3｜用途适配器与图组编排

按顺序建立：

1. 官方内容适配器；
2. 小红书内容适配器；
3. 朋友圈内容适配器；
4. 买家秀内容适配器；
5. 各用途标准图组；
6. 同一品牌母体下的制作感与真实感权重；
7. 不同用途的 QA 和自动选片逻辑。

下一步正式先做 **官方内容适配器**。

原因：

- 正式锚点同时包含生活方式、棚内人物和产品静物；
- 官方内容是最完整的母图组；
- 小红书、朋友圈和买家秀可以在官方内容体系上减少制作感、改变图组比例；
- 先建立官方内容，更容易验证品牌母体是否完整。
